# Seven Palm Interio (द सेवन पाम इंटेरियो) - Web Transformation

A luxury editorial web experience designed for **Seven Palm Interio**, Ranchi's premier interior design & modular kitchen studio (Google 5.0★ Rated, Kilburn Colony, Hinoo, Ranchi).

## Architecture & Features

1. **Luxury Editorial Homepage**
   - Cinematic background with ambient Ken Burns zoom and editorial typography (`Cormorant Garamond` & `Plus Jakarta Sans`).
   - Headline: *"Spaces That Feel Like They Were Made for You."*
   - Prominent CTAs: *"Explore Our Work"* & *"Book a Private Consultation"*.
   - Key Trust Metrics: 10-Year Factory Warranty, 100% On-Time Handover Guarantee, 5.0 Google Rating.

2. **Interactive Project Portfolio**
   - Instant filtering across: *Modular Kitchens, Luxury Apartments, Villas & Bungalows, Commercial & Cafes*.
   - Curated Ranchi localities: *Hinoo, Morabadi, Kanke Road, Lalpur, Doranda, Bariatu*.
   - Interactive Before/After Transformation Sliders with real-time horizontal dragging (mouse & touch support).

3. **Story-Driven Project Case Studies**
   - Interactive modal walkthrough for projects showing: *Client Brief → Architectural Conception → Factory Execution in Ranchi → Specified Material Palette*.
   - Transparent budget brackets (₹4.8L - ₹35L) and verified timeline records.
   - Dedicated *"Discuss a Similar Project"* action that transfers project context straight into the consultation engine.

4. **Premium Multi-Step Consultation Experience**
   - 3-step interactive inquiry wizard:
     - **Step 1:** Property configuration (2BHK/3BHK/4BHK, Villa, Modular Kitchen, Commercial) & Ranchi neighborhood selection.
     - **Step 2:** Budget bracket & start timeline.
     - **Step 3:** Date picker, contact credentials, and meeting preference (Hinoo Studio visit vs On-site inspection).
   - Instant booking reference code (`#SPI-XXXX`) and 1-click WhatsApp transmission to `+91 85218 88983`.

5. **Interactive Design Discovery (Style Quiz & Moodboard Generator)**
   - Aesthetic selector (*Contemporary Warm, Minimal Japandi, Modern Classic, Sleek Italian*).
   - Space selector (*Modular Kitchen, Full Home, Master Suite, Commercial*).
   - Dynamically generated design brief with material and lighting recommendations, ready to transmit via WhatsApp.

6. **Mobile-First Experience**
   - Fixed sticky bottom action bar on mobile devices (*"Call Studio"*, *"WhatsApp"*, *"Book Now"*).
   - Touch-optimized before/after sliders.
   - Authentic Google Reviews showcase featuring real Ranchi feedback (*Saleesh Sharma, Kishor Kumar, Khalfan Farook*).
   - Studio location details: *Near Fun Cinema, Kilburn Colony, Shivpuri, Hinoo, Ranchi 834002 (Plus Code: 88J9+QG)*.

## How to View
Open `index.html` directly in any web browser or serve it using any HTTP server:
```bash
# Python
python -m http.server 3000

# or Node.js / npx
npx serve
```
